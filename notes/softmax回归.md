# softmax回归
分类问题，与线性回归不同，softmax回归的输出是一个向量，通过指数函数使得每个元素非负，并且所有元素和为1，每个类别对应一个元素，为输入的一个概率，表示输入属于该类别的概率。训练时使用交叉熵损失函数，衡量预测分布与真实分布之间的差异，优化模型参数使得预测分布更接近真实分布。

## Guide questions
1. 分类任务是什么
    分类任务是将输入的数据经过模型处理，输出一个类别或概率分布的任务/
2. 模型最后为什么输出多个数
    因为每个数对应一个类别的概率，输出多个数可以表示输入属于不同类别的概率分布。
3. softmax 是干什么的
    softmax函数将模型的输出转换为概率分布，使得所有元素的和为1。它通过指数函数将每个元素放大并保证非负，然后除以所有元素的指数和，得到一个概率分布。
4. 交叉熵 loss 是什么
    交叉熵：H=-p log(q)，其中p是真实分布，q是预测分布。交叉熵衡量了两个概率分布之间的差异，值越小表示预测分布越接近真实分布。
    交叉熵loss：l=-log(q)，其中q是真实类别对应的预测概率。交叉熵loss衡量了模型对真实类别的预测概率，值越小表示模型对真实类别的预测越准确。

## other key points
1. 输出为什么不采用加权的普通除法
    如果采用普通除法，那么输出可能会有负数，采用指数函数保证其非负，同时softmax运算会把其变成和为1的概率分布
$$
y_i = \frac{e^{\mathbf{w}_i^T\mathbf{x}}}{\sum_{j=1}^K e^{\mathbf{w}_j^T\mathbf{x}}}, \quad i = 1, 2, \ldots, K
$$

2. 交叉熵 loss 为什么是 -log(q)
    交叉熵loss衡量了模型对真实类别的预测概率，值越小表示模型对真实类别的预测越准确。因为交叉熵loss是 -log(q)，当q接近1时，-log(q)接近0；当q接近0时，-log(q)趋向于无穷大。因此，交叉熵loss鼓励模型将真实类别的预测概率尽可能接近1，从而提高模型的准确性。
