# ResNet 学习笔记

## 1. 学习目标

看完 ResNet 后，我需要理解的不是完整复现 ResNet，而是：

```text
为什么 ResNet 能训练更深的网络；
为什么 ResNet 可以作为图像特征提取器；
为什么 Stage 02 要使用预训练 ResNet18。
```

本阶段重点：

- 理解残差连接；
- 理解 ResNet 解决的问题；
- 理解 ResNet18 的输入和输出；
- 理解如何去掉最后分类层得到图像特征。

## 2. ResNet 想解决什么问题？

普通神经网络加深后，不一定会变得更好。

理论上，更深的网络表达能力更强；但实际训练中，网络太深可能出现：

```text
训练困难
梯度传播变差
训练误差不降反升
深层网络反而不如浅层网络
```

ResNet 的核心目标是：

```text
让更深的网络更容易训练。
```

它通过残差连接，让网络不必直接学习完整映射，而是学习输入和输出之间的差值。

## 3. 核心概念：残差连接

普通网络层可以理解为：

```text
x → F(x)
```

ResNet 的残差块可以理解为：

```text
x → F(x) + x
```

其中：

- `x` 是输入；
- `F(x)` 是经过卷积层学到的变化；
- `F(x) + x` 是残差块的输出。

简单理解：

> 如果某些层暂时学不到有用变化，模型至少可以通过 `+ x` 保留原始信息。

这样深层网络更容易退化成“接近恒等映射”，不会因为层数增加而明显变差。

## 4. 为什么残差连接有用？

残差连接的作用可以从两个角度理解。

### 角度一：保留信息

输入 `x` 可以绕过中间层，直接传到后面。

这样可以减少信息在深层网络中逐渐丢失的问题。

### 角度二：让网络学习变化量

普通网络要直接学习：

```text
目标输出 H(x)
```

ResNet 让网络学习：

```text
F(x) = H(x) - x
```

也就是学习“需要改变多少”。

如果不需要改变太多，残差部分可以学得很小。

## 5. ResNet18 是什么？

ResNet18 是 ResNet 的一个较小版本，包含 18 层左右的主要可训练层。

它的特点：

- 模型比 ResNet50 小；
- 推理速度较快；
- 适合入门实验；
- torchvision 可以直接加载预训练权重；
- 可以用于图像分类，也可以用于图像特征提取。

Stage 02 使用 ResNet18，是因为它足够经典、轻量，并且适合作为第一个预训练视觉模型。

## 6. ResNet18 的输入和输出

使用 ImageNet 预训练 ResNet18 时，常见输入形状是：

```text
[batch_size, 3, 224, 224]
```

含义：

```text
batch_size：一批图片数量
3：RGB 三个通道
224 × 224：图片高和宽
```

原始 ResNet18 的输出是：

```text
[batch_size, 1000]
```

因为 ImageNet 有 1000 个分类类别。

## 7. 为什么去掉最后 fc 层？

原始 ResNet18 的流程是：

```text
图片
↓
卷积特征提取
↓
全局池化
↓
fc 分类层
↓
1000 类分数
```

如果我们只想要图像特征，而不是 ImageNet 的 1000 类分类结果，可以把最后的 `fc` 层去掉。

代码中常见写法：

```python
model.fc = nn.Identity()
```

这样模型变成：

```text
图片
↓
ResNet18 特征提取
↓
512 维图像特征向量
```

输出形状通常是：

```text
[batch_size, 512]
```

## 8. `nn.Identity()` 是什么？

`nn.Identity()` 表示什么都不做。

输入是什么，输出就是什么。

例如：

```python
model.fc = nn.Identity()
```

意思是：

```text
把原来的分类层替换成一个空操作。
```

这样可以保留 ResNet18 前面提取出的图像特征。

## 9. ResNet 和 Stage 01 的 SimpleCNN 有什么关系？

Stage 01 的 SimpleCNN：

```text
图片
↓
简单卷积层
↓
Flatten
↓
Linear
↓
CIFAR10 的 10 类分数
```

Stage 02 的 ResNet18：

```text
图片
↓
更强的卷积特征提取器
↓
特征向量
```

可以理解为：

> ResNet18 是更强、更成熟、更深的 CNN 特征提取器。

## 10. ResNet 和后续机械臂项目有什么关系？

机械臂不能直接理解原始像素。

它需要把摄像头图像变成模型可以处理的表示：

```text
摄像头图片
↓
视觉模型
↓
图像特征
↓
策略模型
↓
机械臂动作
```

ResNet 可以作为视觉编码器，把图片转换成特征向量。

后续模仿学习中，可能会出现类似结构：

```python
image_feature = vision_encoder(image)
action = policy(image_feature, robot_state)
```

也就是说，ResNet 不是最终目标，而是视觉输入到动作策略之间的一个重要桥梁。

## 11. 关键名词解释

### ResNet

残差网络，通过残差连接让深层神经网络更容易训练。

### Residual Connection

残差连接，把输入 `x` 加到网络输出上，形式是：

```text
F(x) + x
```

### Residual Block

ResNet 中的基本模块，内部包含卷积层和残差连接。

### Identity Mapping

恒等映射，意思是输入什么就输出什么。

### Feature Extractor

特征提取器，把原始图片转换成特征向量。

### Pretrained Model

预训练模型，已经在大规模数据集上训练过，可以直接复用其视觉特征提取能力。

### fc

fully connected layer，全连接层。ResNet18 中最后的 `fc` 层负责输出 ImageNet 1000 类分数。

### ImageNet

大规模图像分类数据集，常用于训练通用视觉模型。

## 12. 自测问题

1. ResNet 想解决什么问题？
    在之前的神经网络中，随着网络层的堆叠，训练误差不降反增，导致更深的网络表现反而不如较浅的网络，ResNet解决的就是这个问题。

2. 残差连接的形式是什么？
    假设目标映射是 `H(x)`，残差块的输出形式是 `F(x) + x`，其中网络主要学习的是 `F(x)=H(x)-x`，也就是输入和目标输出之间需要变化的部分。

3. 为什么 `F(x) + x` 比只学习 `F(x)` 更容易训练深层网络？
    因为神经网络中有些层并不能学到一些有用的变化，而ResNet的残差链接让输入`x`绕过中间层保留了原始输入信息，这样就不会因为层数增加而明显变差。

4. ResNet18 原始输出为什么是 1000 维？
    因为 ResNet18 是在 ImageNet 数据集上预训练的，而 ImageNet 有 1000 个分类类别，所以原始输出是 1000 维的分类分数。

5. 为什么把 `model.fc` 替换成 `nn.Identity()` 后可以得到图像特征？
    因为fc是分类层，作用是将提取的特征输出为1000个类别，而nn.Identity()表示什么都不做，直接输出前面卷积层提取的特征向量，这样就得到了图像的特征表示。

6. ResNet18 去掉最后分类层后，输出特征通常是多少维？
    通常是512维的特征向量。

7. ResNet 和 Stage 01 的 SimpleCNN 有什么关系？
    ResNet18 是一个更强大、更成熟的卷积神经网络特征提取器，相比于 Stage 01 的 SimpleCNN，ResNet18 具有更深的网络结构和残差连接，可以提取更丰富的图像特征。

8. ResNet 对后续机械臂视觉模块有什么帮助？
    ResNet 可以作为视觉编码器，把摄像头捕捉到的图像转换成特征向量，这些特征向量可以作为输入供后续的策略网络使用，帮助机械臂理解环境并做出相应的动作决策。
